# A creature type is chosen in a search window, and shown as a chip on the face

The Hero chooses a creature type as their Rally the Ranks enters (engine ADR 0052) from all 377 there are. A prototype (kept on the branch `prototype/choose-creature-type`) showed three windows: a search list, a chip grid with an A–Z bar, and the Hero's own types with a search box that grows. It also showed three ways to draw the chosen type on the face (a parchment plate on the art, a chip in the chips' row, a strip across the art's foot) and three in the Inspector (State Information, the type written into the rules text, the face's mark). The user chose the search list, the chip and State Information, with the pinned types showing only their names and a slight lightening under the cursor.

**The Creature Type Window is a window of its own, kept through redraws.** `CreatureTypeWindow` is titled "[card]: choose a creature type". Its search box has the keyboard as it opens. The Hero's own creatures' types are pinned under it, each just its name in a slightly larger entry, then every other type as a compact row. Its rows are built once for each decision. Typing only shows, hides and orders them, so a redraw rebuilds nothing and keeps what is typed. A pure class, `CreatureTypeChoice`, works out what is shown: the pinned types, the matches in order (typed letters picked out, names starting with what is typed first), the match Enter chooses, where Up and Down go, and what pointing says.

**The Hero's own types are those of creatures they control, then of creature cards they own in hand, graveyard and library.** They are ordered by how many they control, then how many they own elsewhere, then alphabetically. The library counts because a player knows their own deck list. The honest way to know it within ADR 0021 was to have the engine say it: the Player View's `library_contents` lists the viewer's own library sorted by name, with no IDs, so it says what is there and never in what order. Having the presenter count the deck list from the Encounter Setup was rejected, because it would have to subtract what has left the library and would be a second account of the game beside the engine's. The opponent's types are never pinned: Rally the Ranks pumps only creatures you control.

**Nothing glows green.** Every type can be chosen, so a resting Glow on 377 rows would say nothing. This is an exception to ADR 0047's "a usable entry glows green". A type brightens under the cursor (`ClickCatcher`) and a click chooses it. ADR 0022 holds: the window answers with the type's index in the decision's list, as the Mode Window answers with a mode's, and nothing on the board answers, so `DecisionClicks` gains nothing.

**Enter chooses the lit type.** Once something is typed, the top match is lit (a gold border), and the board follows it as if the cursor were on it, so what Enter will choose is always seen. Up and Down move the light through the matches, held at the ends. Enter with nothing typed and nothing lit does nothing. While the box has the keyboard, letters, Space ("Time Lord" has one), Z and X type into it and pass, undo or cancel nothing. Escape is still the screen's and opens the Pause Menu.

**Pointing at a type marks the Hero's creatures of it in the target color.** The Info Panel does not say what choosing it would do: the user asked that it only ask the question. It asks "Choose a creature type for Rally the Ranks" with no Cancel, since the type is chosen as the spell resolves, after the cast.

**The chosen type is a Chosen Type Chip, first in the Battlefield Face's chips' row.** `ChosenTypeChip` is a Keyword Chip's height and as wide as the type's name, and the keywords have the room that is left. When there are keywords, room is always left for one chip, which may be a "+N". On a small face its words never shrink below 12 px. A name too long for the room is cut short with an ellipsis ("Assembly-W…"), and the Inspector always says it in full.

**The Inspector says it in State Information, not in the rules text.** The entry "Chosen type: Cat" says what it does, each ability that reads it worded with the type in its place, and when it was chosen: "Each Cat creature you control gets +1/+1. Chosen as Rally the Ranks entered." Rules text stays a function of abilities (ADR 0023). When the Villain chooses, no window opens; the chip and the entry say what it chose.
