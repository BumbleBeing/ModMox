# An ability's resolutions are counted on the game state, by source object and ability index

Counting resolutions arrived on the card track with Scythecat Cub, in the Villain deck `steppe_lynx`: "Landfall — Whenever a land you control enters, put a +1/+1 counter on target creature you control. If this is the second time this ability has resolved this turn, double the number of +1/+1 counters on that creature instead." It is the first card that asks how often one of its abilities has resolved, and it brought two more primitives with it: an effect that happens instead of another while a condition holds (CR 608.2c), and doubling counters (CR 701.10e).

**"This is the Nth time" is a Condition, `TimesResolvedThisTurnCondition`, with one field, `times`.** It is true while the ability resolving now does so for the `times`th time this turn, counting itself: the resolutions already recorded, plus one. It reads the resolving ability through the context's own stack object, so off the stack it is false. That makes it useless as an intervening "if" (CR 603.4), which is checked as the ability triggers; it belongs in an `InsteadEffect`, and the card says it there. A Value ("the number of times this ability has resolved this turn") was not built: no card counts with it.

**An ability has resolved once it leaves the stack having resolved.** `AbilityLeftStackEvent` records it when `did_resolve` is true. An ability that is countered (CR 701.6a), whose targets are all illegal (CR 608.2b), or whose intervening "if" no longer holds never resolved, and is not counted. Counting as resolution began would have needed a new event, and the count would then include an ability that went on to do nothing; counting as it leaves needs none, and is why the Condition adds one for itself.

**The count is on the game state, not on the source.** `MmGameState` keeps an `AbilityResolution` for each time an ability resolved this turn, the source object's ID and the ability's place among its abilities, and `times_resolved_this_turn()` counts them. `TurnStartedEvent` clears them, so "this turn" includes the other player's. They are copied with the state, shared since they never change, and in the fingerprint. ADR 0054 records a permission Spent on its own permanent, but a resolving ability's source may already have left the battlefield, and a departed object is frozen and shared between copies: if Scythecat Cub dies with two of its triggers on the stack, the second must still be the second time. Keyed by object ID, a permanent that leaves and returns is a new object whose count starts again (ADR 0008).

**An ability on the stack knows which of its source's abilities it is.** `MmGameObject.source_ability_index` is set from the `AbilityPutOnStackEvent` of an activated ability, and from the `PendingTrigger` of a triggered one, which `TriggerDetection` now gives the ability's place among its source's abilities as it triggers. It is copied and in the fingerprint. So two abilities of one object count apart, and activated abilities are counted as triggered ones are.

**"If [condition], [effect] instead" is an `InsteadEffect`**, with a `condition`, the usual `effect` and the `instead` effect. It checks the condition once as it begins (CR 608.2h), keeps which effect happens as the first of its numbers, and hands the rest to that effect. Unlike an intervening "if", it never stops the ability from triggering or resolving. Both effects' Selections are its own, so either one's target is the ability's.

**"Double the number of [kind] counters on [recipients]" is a `DoubleCountersEffect`.** It works out each recipient's count of that kind as it begins and puts that many more on, as a `CountersPutEvent`, so it is putting counters on (CR 701.10e, 122.6). A permanent with none gets none. A `PutCountersEffect` with a Value counting the counters would have done the same, but would have read "for each" rather than "double".

**`AbilityText` words all three.** "If this is the second time this ability has resolved this turn, double the number of +1/+1 counters on that creature instead.": the condition's ordinal is a word up to "tenth", and in an instead effect a target already named is "that creature" rather than "it", as Oracle words it.

**The AI needs nothing.** The count is game state, so a FULL Agent simulating each target sees the doubling on its copies. A CHEAP Agent puts a helpful effect on its most valuable creature, which is good enough inside a rollout. An `InsteadEffect` gets no Timing Tag of its own (NONE), which suits Scythecat Cub.

Left out until a card needs them (ADR 0001): a choice made on resolution inside either effect of an `InsteadEffect` (it would be asked even when its effect does not happen), "the number of times this ability has resolved this turn" as a Value, copies of an ability counting, the count in the Object View for the GUI to show, and doubling counters on players.
