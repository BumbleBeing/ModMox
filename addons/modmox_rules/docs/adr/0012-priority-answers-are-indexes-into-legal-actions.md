# Priority is answered with an index into the list of legal Actions

A priority decision lists every legal Action (passing first, then other Actions ordered by object ID) and is answered with the index of the chosen one. Answering with the Action's data (such as "cast object 15") was rejected because it needs a second set of validation rules that must agree with legality checking, and an answer could then describe an Action that is not actually legal. With an index, validation is a bounds check and an illegal Action cannot be expressed. Because the list order is deterministic, a decision log of indexes replays exactly. The cost is that saves are only meaningful to the same engine version, which ADR 0010 already accepts. An Action that needs further choices (targets, costs) leads to further Pending Decisions, following CR 601.2.
