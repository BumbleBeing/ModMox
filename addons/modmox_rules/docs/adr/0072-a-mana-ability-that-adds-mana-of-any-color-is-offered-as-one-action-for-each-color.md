# A mana ability that adds mana of any color is offered as one Action for each color

Jewel Thief, cut from the Villain deck `frondland_felidar` until it could be made, brings the Treasure: "When this creature enters, create a Treasure token." A Treasure is a colorless Treasure artifact token with "{T}, Sacrifice this token: Add one mana of any color." (CR 111.10a). It is the first mana ability whose mana's color is chosen, and the first predefined token.

**The color is chosen with the Action.** `AddManaEffect.is_any_color` is "Add one mana of any color" (CR 106.1a). `ActivatedAbility.mana_types_to_choose()` gives the five colors for a mana ability with one, and `ActivateAbilityAction.each_for()` makes an `ActivateAbilityAction` for each, in WUBRG order, its `mana_type` that color; every other ability's Action has `MmMana.NO_TYPE`. At priority `TurnProcedure` lists them in the ability's place, the colors together, so ADR 0012's fixed order holds, an answer is still validated by a bounds check, and a decision log of indexes replays exactly. Activating one carries its color to the effect in the effect context (`MmEffectContext.chosen_mana_type`). A mana ability resolves at once, without the stack (CR 605.3a), so the color fixed as it is activated is the color chosen as it resolves. This is the one exception to ADR 0012's "An Action that needs further choices leads to further Pending Decisions".

**While paying, every color is offered** (`ManaPaymentProgress`) once any of them would pay something still owed: paying {W} with a Treasure offers its {W}, {U}, {B}, {R} and {G}. Mana of a color the cost does not need goes to the pool, as CR 605.3a allows, and the payment goes on; if then nothing on offer pays what is still owed, the cast is rewound as any payment that cannot be finished is (CR 728), and canceling it puts the Treasure back. Every other source is still offered only when its mana pays something, so a Forest is not offered while {W} is owed, and a Treasure is not offered while only {C} is. The user chose every color over only the colors that pay, so the Option Menu shows the same rows while paying as at priority.

**`ManaPayment.can_afford()` counts mana of any color as any one color.** It tries each color as one choice of its source, as it tries each of a dual land's abilities, and a source still pays once, since a Treasure's one ability taps and sacrifices it: a lone Treasure pays {W} or {G}, never {W}{U}.

**A `ChooseColorDecision` on resolution was rejected.** One Action that asked a color as the mana was made would put a decision in the middle of a payment step, where no other decision is asked, and the screen would need a new input for it. With an Action for each color, the Option Menu's five rows are those Actions, each worded by `AbilityText.option_of()` with its color ("{T}, Sacrifice this token: Add {W}."), and the Agent and Auto-tap pick one as they pick any Action. A Treasure with five abilities of one color each was rejected before that: it would print five lines, where the rules give it one. A later card that chooses a color as it resolves ("choose a color") gets a decision of its own.

**The payment planner spends a Treasure last.** `AiPaymentPlanner` ranks a source its mana ability sacrifices after creatures, since it is lost for good, and reads an Action's color from its `mana_type`, so neither Auto-tap nor the Villain makes a color that pays nothing. The Agent never weighs a mana ability at priority, so it cracks a Treasure only to pay.

**A Treasure is a Token Definition like any other** (ADR 0044): `content/tokens/treasure.tres`, named "Treasure Token" (CR 111.4). `AbilityText` knows the predefined tokens (CR 111.10) by their subtype, the name less "Token": one is created as "a Treasure token" ("two Treasure tokens"), its abilities left to the rules, and calls itself "this token", as CR 111.10a words it: "{T}, Sacrifice this token: Add one mana of any color."

Left out until a card needs it (ADR 0001): "Add N mana of any one color", mana in any combination of colors, mana of any color from a spell or an ability that uses the stack, which would choose its color as it resolves, and predefined tokens other than Treasure.
