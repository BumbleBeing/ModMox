# An Activation Restriction may be a condition, and the game state keeps what died this turn

Cult Conscript brought the first activated ability offered only while something about the game holds: "{1}{B}: Return this card from your graveyard to the battlefield. Activate only if a non-Skeleton creature died under your control this turn." (CR 602.5b). Its return works from the graveyard (ADR 0094). It is also the first card that asks what died this turn.

**"Activate only if [condition]" is `ActivatedAbility.condition`, an Activation Restriction beside the others** (ADR 0036): once each game, only as a sorcery, only while attached. It is an `MmCondition`, null for none, asked with the ability's activator as the controller and its source as the source, by `ActivatedAbility.is_condition_met()`. `TurnProcedure._may_activate()` asks it at priority, and `ManaPayment.pays_while_paying()` asks it of a mana ability, so a mana ability whose condition does not hold pays for nothing. It is asked as the ability is offered, not again as it resolves: once activated, the ability resolves whatever has happened since (CR 602.5b restricts activating only). The field is saved with the ability, so a Modification could change it, as it could the other restrictions.

**"A [filter] died [under whose control] this turn" is a Condition, `DiedThisTurnCondition`**, with a `filter` and a `whose`, as a dies trigger has (`ZoneChangeTrigger`). It is true while a permanent put into a graveyard from the battlefield this turn matches the filter and was controlled by `whose`, relative to the ability's controller, each seen as it last existed on the battlefield (CR 608.2h). So Cult Conscript's own death never counts, since it was a Skeleton, and a creature that was exiled or returned to its owner's hand never died (CR 700.4). A token dies too: it goes to the graveyard before state-based actions take it away (CR 111.7, 704.5d). "Died" is said of creatures, so the filter names one; the condition itself does not check, so the words and the rule stay in the filter.

**What died this turn is kept on the game state.** `MmGameState` keeps the ID of each permanent put into a graveyard from the battlefield this turn, recorded by `ZoneChangeEvent` as it is applied, in order. `died_this_turn()` lists them, each found as it last existed with `object_or_last_known()`, since a departed object is frozen and kept (`record_departure()`). `TurnStartedEvent` clears the list, so "this turn" includes the other player's. It is copied with the state and in the fingerprint, as ability resolutions are (ADR 0056), which this follows. Scanning the event log back to the turn's start was the alternative: it needs no new state, but nothing in the rules reads the event log, which is how the outside world learns what happened (conventions, hard rule 6).

`AbilityText` prints the condition as Oracle does, after the other restrictions: "Activate only if a non-Skeleton creature died under your control this turn.", and "Activate only as a sorcery and only if a creature died this turn." when there are two. It is no keyword, so it has no Keyword Chip, Reminder or Keyword Icon. On the Encounter Screen nothing changes: the ability is clicked where it works, and is simply not offered while the condition does not hold.

The Agent needed nothing. It picks from the engine's legal actions, so it sees the ability only while the condition holds, and its simulation weighs the creature returned as any other activation. Cult Conscript's return has no Timing Tag of its own, so it is considered whenever it is offered.

Left out until a card needs them (ADR 0001): a count of what died ("if two or more creatures died this turn"), morbid as an intervening "if" of a triggered ability (it would use this same condition), a Value for the number that died, and "died this turn" for noncreature permanents.

## Addendum: whether a player attacked this turn

Mardu Skullhunter brought raid: "When this creature enters, if you attacked this turn, target opponent discards a card." Raid is an ability word, with no rules meaning of its own (CR 207.2c); what it marks is an intervening "if" (CR 603.4).

**"If you attacked this turn" is a Condition, `AttackedThisTurnCondition`**, with no fields. It is true while the controller of the ability that asks declared one or more attackers this turn (CR 508.1). A creature put onto the battlefield attacking was never declared, so it never attacked (CR 508.4), and a player who declared no attackers did not attack.

**Whether each player attacked this turn is kept on the player**, as the spells they cast and cards they drew this turn are: `MmPlayer.has_attacked_this_turn`, set by `AttackersDeclaredEvent` as it is applied, which is only performed when at least one attacker is declared, and cleared with the player's other counts as each turn begins (`reset_turn_counters()`). It is copied with the player and in the fingerprint. `MmCombat` was the other place it could live, but it forgets its attackers once combat ends and keeps those put onto the battlefield attacking beside the declared ones, which never attacked; its note saying raid would need the two told apart now says where the answer is kept instead.

`AbilityText` prints the condition as Oracle does, "if you attacked this turn", and leaves the ability word off: it has no meaning (CR 207.2c), and Card Faces leave reminder words off too (ADR 0023). It is no keyword, so it has no Keyword Chip.

The Agent needed a Timing Tag, `AFTER_ATTACKING`: a permanent spell with an "enters" triggered ability of its own whose intervening "if" is this condition is considered only in its controller's postcombat main phase. Cast before combat, its ability would never trigger; the Monte Carlo search alone would not reliably hold it back, since a Rollout from the first main phase need not cast it later. The tag is worked out from the card's abilities, so a Modification that changes the condition changes the tag.

Left out until a card needs them (ADR 0001): "if you attacked with N or more creatures this turn", "if a creature attacked this turn" said of the other player, and raid on an activated ability or a spell (this same condition would serve).
