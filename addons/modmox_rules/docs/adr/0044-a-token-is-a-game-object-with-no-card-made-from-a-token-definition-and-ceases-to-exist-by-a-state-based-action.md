# A token is a Game Object with no card, made from a Token Definition, and ceases to exist by a state-based action

Tokens arrived with Prideful Parent, on the card track: "When this creature enters, create a 1/1 white Cat creature token." A token (CR 111) is a permanent that is not a card.

**A token is a Game Object whose Card Identity is `NO_CARD` and whose `is_token` is true.** Emblems and Potions already had no card; a token is the first object with no card that is a permanent. `is_token` is set by an event (`become_token()`), copied with the object, in the fingerprint and in the Object View, where it is public like the permanent. A token is never a Run Card, so nothing about a run (the Spoils, the deck) can see it, and `is_card()` is false for it as it is for an ability on the stack.

**A token is made from a Token Definition, an `MmCardDefinition` in its own file under `content/tokens/`.** The effect that creates it, `CreateTokenEffect` ("Create [amount] [token]", CR 111.2), names that file. A token's characteristics are set by the effect that makes it (CR 111.3), and a Card Definition already holds every one of them, so the characteristics query, the layers and the rules text treat a token like any other object. Its name is its subtypes plus "Token" (CR 111.4), written in the file. It is kept in its own file, not inside the card that makes it, so several cards can make the same token and the GUI can find its art by the file's name. The loaded definition is the token's `definition` and is never changed (ADR 0004), as an Emblem's is. The Object View carries it (`token_definition`) for that one use; the engine reads it only through the characteristics query (ADR 0009). So that the file survives into an encounter, flattening a Run Card (ADR 0004) now copies only the card's own parts, the sub-resources inside its file, and shares any resource that is a file of its own, as it was loaded; such a resource is read-only like the base Card Definition itself. Copying everything had given the token a nameless copy of its definition.

**A token's color comes from a color indicator.** Color was worked out from the mana cost alone (CR 202.2), and a token has none. `MmCardDefinition.color_indicator` (CR 204) lists colors the object has besides its mana cost's; printed characteristics are the union, in WUBRG order. A real card with a color indicator can use it too.

**Creating is one event per token, `TokenCreatedEvent`, all in one batch.** It makes the object under the creating player's control and ownership (CR 111.2), on the battlefield, untapped and summoning sick. It is not a `ZoneChangeEvent`, because nothing moves; but the token does enter the battlefield (CR 603.6a), so `ZoneChangeTrigger` matches it as an arrival from no zone: a trigger that takes any zone it came from sees it, and one that asks for a particular zone does not. The token's own "enters" abilities trigger the same way.

**A token that leaves the battlefield moves like a card and then ceases to exist.** A dying token goes to its owner's graveyard by an ordinary `ZoneChangeEvent`, which carries `is_token` to the new object, so "dies" and "leaves the battlefield" abilities see it (CR 111.7, 700.4). Then a state-based action removes every token that is anywhere but the battlefield, through `TokenCeasedEvent` (CR 704.5d); since state-based actions are checked before anyone has priority, no player ever sees a token in a graveyard, hand or exile. Making the zone change itself remove the token was rejected: "dies" triggers look back at the move (ADR 0017) and need it to be a real move to the graveyard.

**"Nontoken" is a NotFilter of `IsTokenFilter`**, which reads `is_token` on the object or its last known information, so a token that has died is still seen as one (Arahbo, the First Fang: "another nontoken Cat you control").

Left out until a card needs it (ADR 0001): a token that is a copy of something (CR 111.10, 707), predefined tokens such as Treasure (CR 111.10), a Token Definition with abilities in its rules text ("with flying"), and the number of tokens worked out by a Value.
