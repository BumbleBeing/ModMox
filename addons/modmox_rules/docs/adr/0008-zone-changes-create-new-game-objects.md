# A card that changes zones becomes a new Game Object

Following Comprehensive Rules 400.7, whenever a card changes zones it becomes a new Game Object with a new identity and no memory of its previous existence. Anything that refers to a Game Object refers to one specific identity, never to "the card", so "exile that creature at end of turn" correctly fails if the creature left and returned, and counters and attachments are lost. This is in place from the first milestone because making references identity-aware after the fact is notoriously painful. A new object starts untapped, with no counters on it. What an effect says it enters with, counters (CR 122.6) or tapped (CR 110.5b), is carried by the zone change itself and is true of the object as it arrives, so its "enters" abilities see it. So is a choice made as it enters, such as a creature type (ADR 0052), and like everything else it is forgotten when the permanent leaves. A permission Spent once each turn is Spent on its own object, so one that leaves and returns may be used again that turn (ADR 0054).
